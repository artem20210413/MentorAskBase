# Отчёт о проделанной работе — RAG AI Bot (Mentor Search Backend)

Дата отчёта: 01.10.2026

## 1. Технологический стек

- Backend: Laravel 13 (PHP 8.3)
- БД: PostgreSQL + расширение **pgvector** (векторный поиск), Redis (очереди)
- AI: интеграция с OpenAI (чат, эмбеддинги `text-embedding-3-small`, vision-модель для OCR) через `openai-php/laravel` и `llphant`
- Админ-панель: Filament 3
- Публичный чат: Livewire
- Парсинг документов: PDF (`smalot/pdfparser` + vision OCR для сканов), Word (`phpoffice/phpword`), TXT
- Инфраструктура: Docker (Laravel Sail), очереди

## 4. Примечания

- Оценка построена на основе анализа истории git, структуры кода (`app/Services`, `app/Jobs`, `app/Filament`, `app/Livewire`, `app/Http`).
- Часы — экспертная оценка объёма реализованной функциональности, а не фактически залогированное время (тайм-трекинг в репозитории не велся).
- Сделать точный расчёт трудозатрат объективно тяжело: проект стартовал без полноценного ТЗ, значительная часть реализации (архитектурные решения, объём фич, формат агентного режима и т.д.) придумывалась и уточнялась по ходу работы, а не следовала заранее зафиксированному плану. Поэтому цифры в таблице — ориентировочные, а не точный хронометраж.
- В оценку не включены ревью кода заказчиком, деплой на прод-инфраструктуру и поддержка после сдачи — эти работы можно оценить отдельно при необходимости.

# Quickstart: Перевірка агентного пошуку в інтернеті та локалізованих промптів

Передумови: застосунок піднятий (`./vendor/bin/sail up -d`), черга
непотрібна (запити до `/queries` синхронні), дійсний Sanctum-токен API,
дійсний `OPENAI_API_KEY` з доступом до Responses API та вбудованого
інструменту `web_search`.

## 1. Питання, відповідь на яке є лише в інтернеті

```bash
curl -s -X POST http://localhost/api/v1/queries \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"question": "Коли MENTOR отримав схвалення FDA на MemoryGel Enhance найбільшого розміру?"}'
```

**Очікується**: `200 OK`, `sources` містить принаймні один елемент з
`"type": "web"` і посиланням на джерело (FR-002, FR-003, SC-001).

## 2. Питання, що поєднує базу знань і інтернет (User Story 2)

Завантажити документ із частковою інформацією (наприклад, внутрішні умови
гарантії), потім поставити питання, що вимагає і цієї інформації, і
свіжих даних з інтернету (наприклад, порівняння з поточною публічною
інформацією виробника).

**Очікується**: `sources` містить елементи обох типів (`document` і
`web`) в одній відповіді (SC-002).

## 3. Обмежений перелік дозволених сайтів (User Story 1a)

```bash
# .env: RAG_WEB_SEARCH_ALLOWED_DOMAINS=jnjmedtech.com,mentorwwllc.com
```

Поставити те саме питання, що й у кроці 1.

**Очікується**: усі `type: "web"` джерела у відповіді належать до
`jnjmedtech.com` або `mentorwwllc.com` (SC-006). Очистити змінну
середовища → пошук знову необмежений.

## 4. Питання поза спеціалізацією бота (User Story 1b)

```bash
curl -s -X POST http://localhost/api/v1/queries \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"question": "Який рецепт борщу?"}'
```

**Очікується**: відповідь повідомляє, що питання поза межами
спеціалізації бота (грудні імпланти/Mentor), `sources` — порожній масив,
пошук в інтернеті не виконувався (SC-007).

## 5. Медичне застереження (User Story 1c)

```bash
curl -s -X POST http://localhost/api/v1/queries \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"question": "Чи підходить мені операція з імплантами MENTOR при моєму стані здоров'\''я?"}'
```

**Очікується**: відповідь містить чітке нагадування, що бот — ШІ-асистент,
і рекомендацію звернутися до лікаря (SC-008). Порівняти з простим
фактологічним питанням ("З чого виготовлені імпланти MemoryGel?") —
там така рекомендація MUST бути відсутньою чи мінімальною (FR-008f).

## 6. Ліміт кроків "роздумів" (FR-006)

Тимчасово встановити `RAG_AGENT_MAX_STEPS=1` і поставити складне питання,
що потребує і БЗ, і інтернету.

**Очікується**: відповідь усе одно повертається за прийнятний час
(`200 OK`, без тайм-ауту), можливо менш повна — цикл примусово
завершується після 1 кроку (SC-003).

## 7. Локалізовані промпти (User Story 3)

```bash
grep -r "You are a friendly" app/Services/ || echo "OK: промпт не в коді"
cat resources/lang/en/bot.php
```

**Очікується**: текст системного промпту й інших інструкцій бота
відсутній у файлах `app/Services/**/*.php` (перший grep нічого не
знаходить) і присутній у `resources/lang/en/bot.php` (SC-004).
